# فروشگاه یونی‌شاپ

یونی‌شاپ یک فروشگاه فارسی و راست‌به‌چپ با Next.js و SQLite است. پنل مدیریت برای تعریف کالای ساده و متغیر، دسته‌بندی، تعرفهٔ ارسال و بررسی سفارش‌ها استفاده می‌شود.

## راه‌اندازی روی ویندوز

نسخهٔ ۲۲٫۱۳ یا بالاتر از Node.js لازم است. این دستورها را در PowerShell و از پوشهٔ پروژه اجرا کنید.

```powershell
npm.cmd ci
Copy-Item .env.example .env.local
npm.cmd run seed
npm.cmd run dev
```

فروشگاه در [صفحهٔ اصلی](http://127.0.0.1:3000) و پنل در [صفحهٔ ورود مدیر](http://127.0.0.1:3000/admin) باز می‌شود. دستور نمونه اختیاری است و چهار کالا و در صورت خالی بودن فهرست تعرفه‌ها، یک قانون ارسال عمومی با مبلغ ۹۵ هزار تومان اضافه می‌کند. اجرای دوبارهٔ آن تنظیمات کالاهای نمونهٔ موجود را حفظ می‌کند.

### ایجاد اولین مدیر

رمز را در ورودی مخفی PowerShell وارد کنید. نام کاربری در مثال زیر `admin` است.

```powershell
(Read-Host 'رمز مدیر، حداقل ۱۲ نویسه' -MaskInput) | npm.cmd run admin:create -- admin
```

داده‌ها در `data/shop.sqlite` و تصاویر بارگذاری‌شده در `data/uploads` ذخیره می‌شوند. این پوشه با راه‌اندازی دوبارهٔ برنامه باقی می‌ماند. برای پشتیبان‌گیری محلی، پس از توقف برنامه از کل پوشهٔ `data` کپی بگیرید.

## تعریف کالا و ارسال

برای کالای متغیر ابتدا ویژگی‌ها و مقادیرشان را تعریف کنید. «ساخت همهٔ ترکیب‌ها» فقط ترکیب‌هایی را ایجاد می‌کند که هنوز وجود ندارند. قیمت، موجودی، وزن و کد هر ترکیب را تعیین کنید و ترکیب‌های قابل فروش را فعال کنید. برای انتشار کالای ساده، قیمت مثبت و کد کالا وارد کنید. تصاویر با قالب JPEG، PNG یا WebP و حداکثر حجم ۲ مگابایت پذیرفته می‌شوند.

در قوانین ارسال، عدد اولویت کمتر زودتر بررسی می‌شود. شرط‌های هر قانون با هم سنجیده می‌شوند. وجود یک کالا از دسته‌های انتخابی شرط دسته را برقرار می‌کند. تعداد، وزن و مبلغ از کل سبد محاسبه می‌شوند و ابتدا و انتهای بازه نیز معتبرند. اگر تعرفهٔ عمومی می‌خواهید، قانون بدون شرط با عدد اولویت بزرگ‌تر بسازید. مبلغ صفر یعنی ارسال رایگان.

## پرداخت زرین‌پال

حالت پیش‌فرض `PAYMENT_MODE=sandbox` است. مشتری به صفحهٔ آزمایشی زرین‌پال هدایت می‌شود و هیچ مبلغ واقعی پرداخت نمی‌شود. مقدار پیش‌فرض شناسهٔ آزمایشی در فایل نمونه درج شده است. در صورت نیاز می‌توانید آن را با `ZARINPAL_SANDBOX_MERCHANT_ID` تغییر دهید.

برای آزمون آفلاین، مقدار `PAYMENT_MODE` را به `simulator` تغییر دهید و برنامه را دوباره راه بیندازید. شبیه‌ساز حالت‌های موفق، لغو و قطع ارتباط را ارائه می‌کند. سفارش‌های در انتظار بررسی را می‌توانید در جزئیات سفارش دوباره بررسی کنید.

برای پرداخت واقعی، مقدار `PAYMENT_MODE=live`، شناسهٔ پذیرنده در `ZARINPAL_MERCHANT_ID` و نشانی HTTPS مورد قبول زرین‌پال در `APP_URL` لازم است. اگر نشانی یا پورت اجرای آزمایشی را تغییر دادید، `APP_URL` را نیز مطابق آن تنظیم کنید. درگاه برای بازگشت از مسیر `/payment/return` استفاده می‌کند. شناسهٔ پذیرنده را در فایل محیطی سمت سرور نگه دارید.
